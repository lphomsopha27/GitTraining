📖 INVESTIGATOR'S GIT MANUAL

  • git status

    Shows current case progress and triggers fade transition to the Corkboard view ("WHO?").

  • git branch [evidence_name]

    Pins a piece of evidence onto the Corkboard. Valid files: videologs, atTheScene, witness1, witness2.

  • git checkout [evidence_name]

    Dives into / portals inside the pinned evidence file to inspect logs & interrogation code.

  • git commit -m "findings"

    Summarizes and documents findings on the active evidence branch.

  • git checkout main

    Leaves the portal and returns to the Main Detective Desk.

  • git merge [evidence_name]

    Connects the RED STRING from the documented evidence to the main "WHO?" case board!
